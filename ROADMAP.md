# SelfCall — план работ

Цель: личный сервис видеовстреч по ссылке, по образцу Яндекс Телемоста. Чаще всего это звонки с директором.

**Стек:** LiveKit (SFU) + Nginx + FastAPI + React + Kotlin (Android) + Swift (iOS).

История: этапы 0–2 первой версии (эксперимент с 5 фиксированными комнатами) описаны в git-истории до ноября 2026.

---

## Этап 1 — Бэкенд: встречи по ссылке ✅

- [x] `POST /api/meetings` — создать встречу, ID вида `abc-defg-hjk` с подписью HMAC
- [x] `GET /api/meetings/{id}` — состояние встречи и число участников
- [x] `POST /api/meetings/{id}/join` — токен, имя необязательно («Гость»)
- [x] Лимиты: 10 встреч на сервере, 10 человек во встрече, ограничения по IP
- [x] Автозакрытие пустых встреч средствами LiveKit, жёсткий предел 8 часов
- [x] Закрытая встреча открывается снова при входе по той же ссылке
- [x] Тесты (pytest, 8 шт.)

## Этап 2 — Веб-версия ✅

- [x] Главная: «Создать встречу» и вход по ссылке или коду
- [x] Экран перед входом: превью камеры, индикатор микрофона, выбор устройств, имя по желанию, ссылка с копированием
- [x] Звонок: сетка, а при демонстрации экрана — крупный экран и лента камер
- [x] Кнопки микрофона, камеры (с выбором устройства), экрана (со звуком в Chrome), выхода
- [x] Код встречи в верхней панели копирует ссылку; пока вы одни, кнопка выделена и рядом подсказка. Видео ничем не закрыто
- [x] Понятные ошибки: встреча не найдена, сервер занят, нет мест, нет доступа к камере
- [x] Проверка по скиллам better-*: доступность, раскладка, тексты, типографика, цвета, полировка
- [x] Локальный запуск в Docker: `infra/local/docker-compose.yml`
- [ ] Ручная проверка с настоящей камерой и демонстрацией экрана в Chrome и Safari

## Этап 3 — Деплой на сервер в Армении

- [x] Осмотр сервера: офисный мини-ПК за роутером, рядом Gamma, ресурсов хватает
- [x] Docker Compose для продакшена: web + backend + LiveKit, один домен, сигналинг по `/rtc`
- [x] Конфиг для nginx хоста (отдельный файл, установка с `nginx -t` и откатом), скрипт деплоя с Mac
- [x] LiveKit обновлён до 1.13.11: ошибки `/rtc/v1` в консоли больше нет
- [x] Домен `call.gamma.help`, A-запись на `188.164.152.23`
- [x] Порты: роутер уже отправляет весь трафик на сервер, TCP 7881 и UDP 7882 доходят до LiveKit
- [x] Первый деплой: `.env` и контейнеры на сервере
- [x] Сайт в nginx хоста и сертификат Let's Encrypt (автопродление certbot)
- [x] Звонок через интернет с ботом: видео идёт и по UDP 7882, и по TCP 7881
- [ ] Проверка: звонок через мобильный интернет, из офисной сети, из корпоративной сети
- [ ] По желанию: UDP-буферы на сервере, TURN/TLS на 443 для сетей, где открыт только 443
