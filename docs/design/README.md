# Экраны SelfCall

| Клиент | Экраны и варианты | Макет |
| --- | --- | --- |
| Веб | Главная, подготовка к встрече, только что созданная встреча | [Начало встречи](web-start.webp) |
| Веб | Звонок, меню устройств, проверка ссылки, выход, ошибка | [Звонок и состояния](web-call.webp) |
| Android | Главная, вход в SelfCall, проверка ссылки, подготовка к встрече | [Начало встречи](android-meetings.webp) |
| Android | Список коллег, настройка входящих, входящий и исходящий вызовы | [Звонки коллегам](android-colleagues.webp) |
| Android | Активный звонок, выход, ошибка, обязательное обновление | [Звонок и состояния](android-status.webp) |

На каждом листе показаны основные состояния. Загрузка, отсутствие доступа к устройствам, пустой список, предложение обновиться и повторная попытка описаны в [дизайн-системе](../../DESIGN.md) и используют те же компоненты. Запросы разрешений, отправка ссылки и установка APK открываются средствами Android. Запрос доступа к сайту открывает браузер.

## Приёмы движения

| Пример | Применение в SelfCall |
| --- | --- |
| Copy button | Галочка и подпись подтверждают копирование ссылки |
| Loading to success | Создание встречи переходит из ожидания в экран с выделенным приглашением |
| Spring dropdown | В веб-звонке меню устройств раскрывается от управляющей кнопки. Галочка показывает действующее устройство |

Источник примеров — [DesignBookmark Motion](https://designbookmark.com/motion).

Макеты созданы встроенным ImageGen. [Запросы к генератору](imagegen-prompts.md).
